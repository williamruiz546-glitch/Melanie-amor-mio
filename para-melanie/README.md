# Para Melanie ❤️

App de regalo: portada con canción, contador desde el 15 de marzo de 2025, mensaje del día,
galería de fotos, razones, historia, cartas "Abre cuando…", mapa de recuerdos, juego con premio y cupones.

## Archivos
- `index.html`: toda la app. Los textos se editan en el bloque `DATOS` al inicio del `<script>`.
- `foto1.jpg` … `foto10.jpg`: fotos optimizadas para celular.
- `cancion.mp3`: nuestra canción.

## Publicar en Render (Static Site)
1. New → Static Site → elegir el repo `Melanie-amor-mio`.
2. Root Directory: `para-melanie`
3. Build Command: dejar vacío.
4. Publish Directory: `.`
